# AI Architectural Rules & Guardrails

## Non-Negotiable Rules

1. **No Direct Database Access**:
   The LLM never connects directly to PostgreSQL. It interacts exclusively through explicit tool signatures.
2. **Deterministic Validation**:
   Outputs generated by the LLM must be validated through Pydantic schemas before any database write or backend execution.
3. **Execution Boundary**:
   State-changing actions (creating tasks, assigning members, publishing announcements) require validation through the backend API authorization pipeline.
4. **Idempotency**:
   AI action requests must be idempotent to prevent duplicate tasks when processing meeting minutes or transcripts.
